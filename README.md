# OrbitTime Landing Page

A responsive single-page marketing website built with plain HTML, CSS, and JavaScript, based on the design reference provided in chat.

## Files

- `index.html` — page structure and content
- `style.css` — responsive styles and visual design
- `script.js` — mobile navigation, pricing billing toggle, and newsletter form feedback

## Run locally

Open `index.html` in your browser. No build tools or dependencies are required.

## Notes

- The team and testimonial photos are loaded from Unsplash, and Google Fonts are loaded remotely.
- The newsletter form is front-end only. Connect it to an email provider or backend before collecting real subscribers.
- Brand copy, contact address, and pricing are sample content and can be replaced with your actual portfolio/business details.
